# Git cheat sheet

- `git status` — holatni ko'rish
- `git add .` — staging'ga qo'shish
- `git commit -m "..."` — commit yaratish
- `git log --oneline --graph` — tarixni ko'rish
- `git switch -c feature/...` — branch ochish
- `git merge feature/...` — branch'ni qo'shish
- `git remote -v` — remote URL'larni ko'rish
- `git push` — GitHub'ga yuborish
- `git pull` — yangilanishlarni olish
- `git fetch --prune` — o'chirilgan branch izlarini tozalash
